🚆 Getafe ↔ Madrid / Bernabéu 交通 Transport

Getafe Centro：属于 Cercanías C-4；Getafe → Sol / Nuevos Ministerios 为直达走廊。最简单支付方式是 Renfe Cronos：Visa/Mastercard 实体卡或手机在进站和出站都要拍卡，系统按实际区域自动收单程票价。

建议：两人各用自己的卡/手机，减少重复拍卡出错。不要为了两天行程提前买复杂通票。

10/6 Bernabéu：2026 年 Santiago Bernabéu 站施工，L10 的 Cuzco–Nuevos Ministerios 段暂停到年底。到 Nuevos Ministerios 后，换官方免费 S10 替代公交去 Bernabéu；工作日官方班距约 2–3 分钟。

🏨 ibis Madrid Getafe Hotel

官方当前：check-in 从 12:00 起、check-out 至 12:00；24h 前台。早餐周一至周五 06:30–10:30，明确为 hot + cold buffet。

房型基线：一张 double / queen-type bed + private bathroom；Ctrip 最终付款页仍要确认具体 rate 保证一张大床。

10/7 不使用酒店寄存作为主方案：虽然酒店有 luggage storage，但回 Getafe 取行李会造成不必要折返。

⚽ Tour Bernabéu / Official Store Core

Classic Flexible Time：当前官方 €44/人；10/6 周二正常开放 09:00–19:00。Flexible Time 可在所选日期的开放时段内自由到场。

当前路线包括 Real Madrid Museum、球场内部全景、dressing rooms、dugouts，并在可用时临时开放 press room；活动日路线仍可能临时缩短。

执行：目标 10:00 开始，约 12:00 结束；随后给 Official Store 预留 20–30 分钟。

商店：官方现有 kits、training、fashion、accessories、club merchandise、collectibles 与个性化区。不要预设一定有 Cristiano Ronaldo 专属库存；到现场再看 legends / historical stock，并可询问是否允许 “RONALDO 7” 定制。

👑 Palacio Real de Madrid Core

10 月开放：周一至周六 10:00–18:00，停止售票和入场比闭馆早 1 小时。

自助基础票：当前 €18/人；普通自助宫殿参观约 45 分钟。网站按约 14:30–16:00 留出完整缓冲，仍建议提前买官方 timed entry。

王宫可能因官方活动临时关闭。10/6 前 1–2 天再看一次 Patrimonio Nacional 通知；若临时关闭，再单独处理，不提前把 Prado / Retiro 塞进基础路线。

🌅 Templo de Debod Good-to-have

10/6 日落：约 19:49。计划 18:30 左右到 Debod，主要看外观、城市天际线与日落。

官方内部周二 10:00–20:00，19:30 最后入内，免费；但小型室内不是核心。如果要入内，尽量 19:15 前完成，别为了室内错过日落。

天气差、体力差或王宫拖延时，Debod 第一个删除。

🧳 Golden Locker Plaza España 10/7 luggage

地址：Calle Fomento 37, Local 2，靠近 Plaza de España；24h / 365 天自助。

L 柜当前 €10.90/天，官方说明可放 2 个 10kg cabin suitcases；如果你们箱子尺寸明显更大，应改 XL。

流程：提前在线预约并付款 → SMS / email 收到入口与 locker code / QR → 现场自助。建议 10/4–10/5 左右确认箱子尺寸后预订，并把地址、确认邮件和二维码同时离线保存到两部手机。

✈ 10/7 MAD → Manchester Schengen exit

已核：easyJet U22050，10/7 23:15 MAD → MAN 00:45 次日；easyJet 在 Madrid 使用 T1，Manchester 航线也列在 T1。

网站目标：约 19:15 从 Golden Locker 一带叫 Uber / taxi，争取 20:00–20:15 抵达 T1，留约 3 小时。

你们有托运行李；T1 去英国还需要在安检后完成出境证照流程。easyJet 的最终 bag-drop / gate closing time 以 booking confirmation / app 为准，不拿“关柜时间”当计划到机场的目标。

10/7 是申根停留最后一天。宁可少逛 30–60 分钟，也不压缩机场缓冲。

🍽 吃饭 Food

早餐：10/6、10/7 都在 ibis 吃完热+冷 buffet 再出发。

10/6 午饭：Bernabéu Store 后，在附近/去王宫路上找普通、刷卡方便、无需久等的餐厅；排队 >15–20 分钟就换。

10/6 晚饭：Debod 后在 Plaza de España / Gran Vía 一带灵活解决。

10/7：Mercado de San Miguel 只短看/吃小食；正餐可在周边普通餐馆。傍晚如果不方便正式吃饭，就机场再吃。

⚠️ 晚点 / 故障怎么删 Contingency
  1. 10/5 FR5483 晚点：无论多晚都机场 → ibis，取消任何临时夜游。
  2. 10/6 C-4 / S10 异常：在最方便的位置直接 Uber 去 Bernabéu，不拿已付核心票换交通省钱。
  3. 10/6 进度落后：先缩短 Plaza de España；再删 Debod。Bernabéu 和王宫内部不删。
  4. 天气差：直接删 Debod。
  5. 10/7 locker 故障：先找另一个自动 locker；必要时才用人工寄存；不要回 Getafe 寄存。
  6. 10/7 时间落后：购物、咖啡、晚饭都可删；19:00 左右必须回 locker 进入机场链条。

现场原则

不重新加入 Prado + Retiro；不把 Debod 升级为核心；不返回 Getafe 取行李；不使用旧的 L10 直达 Bernabéu 路线。

10/6 的两个核心是 Tour Bernabéu + Palacio Real interior；10/7 的核心是“市中心 locker → 老城单向走 → T1 提前约3小时”。
