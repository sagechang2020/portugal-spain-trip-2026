# Portugal / Spain Trip 2026

Mobile-first execution guide for the 2026 Portugal / Spain trip.

Current content: **Madeira / Funchal (2026-09-30 to 2026-10-02)**.

Planned site URL after GitHub Pages is enabled:

https://sagechang2020.github.io/portugal-spain-trip-2026/

## One-time GitHub Pages activation

Open **Settings → Pages** for this repository and set **Source** to **GitHub Actions**. Then re-run the existing workflow under **Actions → Deploy travel guide to GitHub Pages**, or push any later update. Subsequent updates deploy automatically.

## Site features

- mobile-first Chinese + Portuguese/English execution guide
- Leaflet + OpenStreetMap interactive route map
- Apple Maps / Google Maps navigation links
- Uber deep links for important ride segments
- day tabs and an automatic “next step” card during the trip
- real web-sourced attraction photos
- ticket, food, luggage, budget and disruption rules
- PWA/service-worker support for cached offline reading

Lisbon, Porto and Madrid will be added to the same app later.
